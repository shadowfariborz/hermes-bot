# 🤖 Fariborz Bot (Python/Railway)

ربات تلگرام فریبرز — نسخه پایتون برای Railway

## قابلیت‌ها
- 💬 چت هوشمند (Hermes API)
- 📷 دریافت و تحلیل عکس
- 🎤 پیام صوتی → متن (STT)
- 🔊 متن → صدا (TTS)
- 🎨 ساخت عکس
- 🎵 شناسایی آهنگ (ACRCloud)
- 🦖 بازی دایناسور با رتبه‌بندی
- 📢 ارسال همگانی
- 👨‍💻 پنل ادمین

## متغیرهای محیطی

| متغیر | توضیح |
|--------|--------|
| `TELEGRAM_BOT_TOKEN` | توکن بات تلگرام |
| `HERMES_API_URL` | آدرس API هرمس |
| `API_SECRET` | کلید API (پیش‌فرض: fariborz-hermes-2024) |
| `ADMIN_ID` | آیدی ادمین اصلی |
| `ADMIN2_ID` | آیدی ادمین دوم |
| `ACR_HOST` | هاست ACRCloud |
| `ACR_ACCESS_KEY` | کلید دسترسی ACRCloud |
| `ACR_SECRET_KEY` | کلید مخفی ACRCloud |

## دپلوی روی Railway
1. این ریپو رو به Railway متصل کنید
2. متغیرهای محیطی رو در Variables تنظیم کنید
3. Deploy بزنید
4. از صفحه اصلی سرویس، آدرس پابلیک رو کپی کنید
5. به ربات تلگرام پیام بدید: `/setup@botname` یا وبهوک رو دستی تنظیم کنید
